# LIT Saúde Mental · protótipo

Protótipo funcional da LIT Digitall com dois produtos:

- **Clínica digital de saúde mental:** agendamento com termo de consentimento e pagamento, agenda da médica, teleconsulta, prontuário com PHQ-9, prescrição, assinatura digital, financeiro e auditoria LGPD.
- **Plataforma de assessoria NR-01:** empresas clientes, questionário anônimo, mapa de riscos psicossociais por setor, plano de ação e relatório técnico para o PGR.

Todos os dados são fictícios e ficam salvos apenas no navegador de quem acessa. Pagamentos, vídeo e assinaturas digitais são simulados.

Página única em HTML, CSS e JavaScript, sem dependências.
